# 语法检查

实现分两层：逐行 `_CheckLine`，全文 `_FileCheck`（由 `CheckAll` 调用）。

## 9 类错误

| # | 类别 | 颜色 | 例子 |
|---|---|---|---|
| 0 | 缺少冒号 | 黄 `0xFFE0` | `if x==1` |
| 1 | 缺少逗号 | 橙 `0xFD20` | `f(a b)` |
| 2 | 缺少空格 | 青 `0x07FF` | `a=[1,2]`、`if(x)` |
| 3 | 未声明变量 | 品红 `0xF81F` | 拼错的变量名 |
| 4 | 括号引号不匹配 | 紫 `0xB01F` | `f(a]`、单引号未闭合 |
| 5 | 缩进混用 | 蓝 `0x441F` | 同一缩进里 tab 和空格混用 |
| 6 | 全角标点 | 粉 `0xFB6B` | `print（x）` |
| 7 | 条件里用了 `=` | 红 `0xF800` | `if x = 1:`、`while (y = 2):` |
| 8 | 关键字拼写可疑 | 白 `0xC618` | `whlie`（含相邻字母写反） |

## 全文级检查

| 检查 | 报在哪 |
|---|---|
| 括号到文件末尾还没闭合 | 被打开的那个括号 |
| `"""` / `'''` 数量为奇数 | 最后一行 |
| 上一行以 `:` 结尾、下一行顶格 | 下一行（缺缩进） |

## 实现要点

- **全角标点**用引号状态机扫（不在字符串、不在 `#` 注释里），不看分词结果，中文串不会误报
- **条件里的 `=`**：行首关键字属于 `if/elif/while` 且出现单独 `=` token
- **拼写**：首词不是关键字但与语句关键字只差一个字符（替换 / 增删 / 相邻互换）
- 含中文的行只做缩进与全角检查，不跑未声明变量，否则整句标红

## 触发时机

| 时机 | 行为 |
|---|---|
| 打开文件 | 立即整篇 `CheckAll()`，左下角“问题 N”立即有数 |
| 敲键编辑 | 逐行重算当前行 |
| 展开问题面板 | 再跑一次 `CheckAll()`，面板计数是全文的 |
| 开机还原 | 上次面板是展开的就展开，并跑全文检查 |

上限 400 行（`CheckAll(limit=400)`）。
