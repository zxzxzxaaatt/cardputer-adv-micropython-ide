# v5 改动（2026-11-26）

## 语法检查升级
原有 6 类保留。新增 3 类：

| 类别 | 颜色 | 例子 |
|---|---|---|
| 全角标点 | 粉 | `print（x）` |
| 条件里用了 `=` | 红 | `if x = 1:` / `while (y = 2):` |
| 关键字拼写可疑 | 白 | `whlie`（含相邻字母写反） |

新增 3 项全文级检查（`CheckAll`）：括号未闭合、三引号奇偶、`:` 后未缩进。

行为变化：打开文件即整篇检查一次，左下角“问题 N”开机就有数；面板头部自动适配 9 类计数色块。
