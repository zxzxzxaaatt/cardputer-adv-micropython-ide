# Cardputer ADV · MicroPython IDE 固件

M5Stack Cardputer ADV（ESP32-S3 / 16 MB Flash / 无 PSRAM）上的一套中文图形 IDE，跑在 MicroPython 1.29 上。屏幕 240×135、键盘是 Cardputer 的 56 键（带 Fn 层）。

当前版本 **v5**（2026-11-26）· [English summary](README_EN.md) · 实机照片见 [实机演示](#实机演示)

## 1. 界面布局

```
┌──────────────────────────────────────────────┐  ← 顶栏 16px
│ demo.py                                  12:5 │     左：文件名（未保存带 *）
├────────┬─────────────────────────────────────┤     右：行:列 / 当前焦点 / 提示
│        │                                     │
│ 文件栏 │           编辑区                     │
│ 60px   │                                     │
│（可关）│                                     │
│        ├─────────────────────────────────────┤  ← 终端面板（半屏 1 / 全屏 2）
│        │ 终端                        Ctrl+`  │
├────────┴─────────────────────────────────────┤  ← 问题面板 32px（可拉出/收起）
│ 问题 7 ■3 ■2 ■1 ■1      1/7                  │
│ 缺少冒号  if x==1                             │
└──────────────────────────────────────────────┘
```

- **顶栏**：左边文件名（改过未保存会加 `*`），右边显示 `行:列`；打开命令面板 / 焦点在终端 / 焦点在文件栏 / 焦点在问题面板时，右边改成显示 `命令` / `终端` / `文件` / `问题`；任何临时提示（“已保存”“主题 绿色”）也显示在这里。
- **侧栏**：宽 60px，关掉就是**禅模式**，打开就是**全分隔模式**。
- **终端面板**：三态循环 关 → 半屏 → 全屏，标题栏右侧写着 `Ctrl+`` 提示。
- **问题面板**：高 32px，头部一行是“问题 + 9 类彩色计数”，下面一行是选中那条的详情。
- **编辑器左下角**：常驻一个黄色小块 `问题 N`，就是当前全文错误条数。
- **输入法候选条**：组词时浮在光标下方，每页 5 个候选。

## 2. 语法高亮：颜色与判定规则

逐行分词上色，颜色全部来自调色板。**含中文的行整行不高亮**（MicroPython 的字符串按字节索引，逐字节分词会把一个汉字算成 3 段宽度，字会跑到屏幕外；中文行按整行渲染，走 `cjktext` 的双宽排版）。

| 类别 | 颜色 | 判定 |
|---|---|---|
| 普通名称 | 白 `0xFFFF` | 既不是关键字/常量/内置，也没被识别为变量 |
| 关键字 | 黄 `0xFFE0` | `if/elif/else/for/while/def/class/return/import/from/as/try/except/finally/with/lambda/global/nonlocal/assert/del/raise/yield/pass/break/continue/async/await/match/case` 等 |
| 字符串 | 绿 `0x07E0` | 单双引号串，含 `f"…"`、`r"…"`、`b"…"`、`rb"…"` 前缀 |
| 文档字符串 | 深橙 `(127,64,0)` | 三引号 `"""` / `'''` 成对包裹的串 |
| 注释 | 灰 `(127,127,127)` | `#` 到行尾 |
| 数字 | 橙 `(255,127,0)` | 十进制、`0x`/`0b`/`0o` 进制、`.5` 开头、`1_000` 下划线、`1e-3` 指数 |
| 常量 | 紫 `(192,0,255)` | `True/False/None/NotImplemented/Ellipsis/__debug__` |
| 函数名 | 青 `0x07FF` | `def` 后的名字；调用形式 `name(`；内置函数与 `re/os/math/time/gc/sys…` 的已知函数 |
| 类名 | 品红 `0xF81F` | `class` 后的名字 |
| 装饰器 | 深紫 `(96,0,127)` | 行首 `@` 起的整段（含点号路径） |
| 变量 | 蓝 `0x001F` | 括号外赋值目标 `x =`、`x +=`；已出现在变量集合里的名字 |
| 参数 | 深青 `(0,127,127)` | `def f(...)` 括号内、以及括号内的关键字/默认参数赋值 |
| `self` / `cls` | 深品红 `(127,0,127)` | 单独识别 |
| 内置类型 | 深绿 `(0,127,0)` | `int/str/list/dict/tuple/set/bytes/bytearray/float/bool/object/range…` |
| 模块名 | 暗黄 `(127,127,0)` | `import x`、`from x import y` 里的 x/y |
| 魔术方法 | 暗红 `(127,0,0)` | `__init__`、`__repr__` 这种双下划线包裹 |
| 运算符/标点 | 红 `0xF800` | 括号、逗号、冒号、算术与比较运算符等 |
| 成员 | 深蓝 `(0,0,127)` | 点号后、不是调用也不是已知库成员的标识符 |

## 3. 语法检查：9 类错误 + 全文级检查

编辑器里用**同色下划线**标出出错的字节区间，问题面板里用**同色小方块 + 数字**统计各类数量。

| # | 类别 | 颜色 | 触发例子 |
|---|---|---|---|
| 0 | 缺少冒号 | 黄 `0xFFE0` | `if x==1`、`def f(a)` |
| 1 | 缺少逗号 | 橙 `0xFD20` | `f(a b)`、`[1 2]` |
| 2 | 缺少空格 | 青 `0x07FF` | `a=[1,2]`、`if(x)`、`f(a,b)` |
| 3 | 未声明变量 | 品红 `0xF81F` | 用了从未定义/导入的名字 |
| 4 | 括号引号不匹配 | 紫 `0xB01F` | `f(a]`、单引号未闭合 |
| 5 | 缩进混用 | 蓝 `0x441F` | 同一段缩进里 tab 与空格混用 |
| 6 | 全角标点 | 粉 `0xFB6B` | `print（x）`、`if x：` |
| 7 | 条件里用了 `=` | 红 `0xF800` | `if x = 1:`、`while (y = 2):` |
| 8 | 关键字拼写可疑 | 白 `0xC618` | `whlie`（只差一个字母 / 相邻字母写反） |

**全文级检查**（逐行看不到的，由 `CheckAll` 统一做）：

| 检查 | 标记位置 |
|---|---|
| 括号一直到文件末尾都未闭合 | 被打开的那个括号上 |
| `"""` / `'''` 数量为奇数（多行串没闭合） | 最后一行 |
| 上一行以 `:` 结尾，下一行却顶格（空 def / 空 if / 空 for） | 下一行的缩进位置 |

**几个实现细节：**

- 全角标点用**引号状态机**扫（只扫字符串/注释外面的字符），所以 `s = "中文，测试"` 不会误报。
- 条件里的 `=`：行首是 `if/elif/while`，且行内出现单独的 `=` token；函数默认参数 `f(a=1)` 不算。
- 含中文的行只做缩进和全角检查，不跑未声明变量——否则一句中文会被整句标红。
- 检查是**增量**的：只重算改动行；`CheckAll()` 才整篇过一遍（上限 400 行）。

**触发时机：**

| 时机 | 行为 |
|---|---|
| 打开文件 | 立即 `CheckAll()`，左下角 `问题 N` 马上有数 |
| 敲键编辑 | 重算当前行 |
| 展开问题面板 | 再跑一次 `CheckAll()`，计数是全文的 |
| 开机还原 | 上次面板是展开的就展开，并跑全文检查 |

**问题面板操作：** `↑/↓`（或 Fn 层 `.` / `;`）上下选，选中项会同时把光标跳到对应行；`Enter` 回到编辑并把光标放到那一行；`Esc` 回编辑。顶部 `1/7` 是当前第几条 / 共几条。实机效果见 [末尾那张问题面板照](#实机演示)。

## 4. 自动补全：能补什么、怎么补

**触发**：在编辑区连续输入字母/数字/下划线，且当前词长度 **≥ 2** 时自动算一次。

**候选来源**（两类合并）：

1. **内置词表**：内置类型、内置函数、常量、全部关键字。
2. **本文件自定义名**：高亮扫描时收集到的 `def` 函数名、`class` 类名、`def` 参数、括号外赋值目标、`import` 进来的名字——也就是**自己写的变量和函数也能补**（`my_counter` 打 `my_` 就会提示）。

**点号成员补全**：光标前是 `.` 时切到成员词表（模块/对象的常见成员，如 `os.listdir`、`str.upper`、`list.append`），不会拿全局词表乱填。

**显示方式**：补全结果不是弹窗，而是**灰色 ghost 文本**直接画在光标后面（类似 IDE 的 inline suggestion）。

| 情况 | 行为 |
|---|---|
| 只有 1 个候选 | ghost 显示完整剩余部分 |
| 多个候选 | 只补它们的**公共前缀**；前缀没比已输入的长就不显示 |
| 按 `Tab` | 接受 ghost，一次性插入；没有 ghost 时 `Tab` 是把光标对齐到下一个 4 列制表位 |
| 继续输入且字符 == ghost 首字符 | 逐个“吃掉” ghost，不会重复插入 |
| 输入其他字符 | 先把 ghost 提交再输入该字符 |
| 退格 / 移动光标 / Esc | 清掉 ghost |

## 5. 中文输入法

**中英切换**：**单击 `Fn` 键**（如果 Fn 被当成组合键前缀用了，则不触发）。光标处显示 `中` / `英` 状态。

**候选逻辑：**

- 输入 `a`–`z` 累积拼音缓冲，实时出候选；
- **完整音节**（`shi`、`ji`）：词组只给**拼音完全相等**的（`nihao` → 你好），最多 2 个，避免打 `shi` 先冒出“失败/士兵”；后面接单字；
- **没打完且 ≥3 字母**（`bangm`）：给 2 个前缀词组，手感接近桌面输入法；
- 单字候选按“**词频 → 常用字序**”排：同一个字上屏满 3 次就排到该音节第一位（像手机输入法记你的习惯）；
- **每页 5 个候选**，候选条浮在光标下方。

**按键：**

| 按键 | 作用 |
|---|---|
| `Tab` | 循环切换高亮候选（到末尾回到第一个） |
| `1`–`9` | 直接选当前页第 1–9 个（页内只有 5 个时只响应 1–5） |
| `空格` | 上屏当前高亮候选 |
| `Enter` | 上屏当前高亮候选（回车不换行） |
| `Backspace` | 删一个拼音字母，删空就退出组词 |
| `Esc` / 方向键 | 取消组词，拼音缓冲清空 |
| 标点或其他字符 | 先把高亮候选上屏，再输入该字符 |

词频落盘在 `imefreq.txt`，每 4 次上屏写一次；删掉该文件等于清空学习记录。

## 6. 编辑操作与文本行为

| 操作 | 行为 |
|---|---|
| `↑`/`↓`/`←`/`→` | 移动光标；上下移动时保持“目标列”`mc`，短行不会把列号弄丢 |
| `Enter` | 换行并**自动缩进**：沿用当前行缩进；若当前行（去掉注释后）以 `:` 结尾，再多缩 4 个空格 |
| `Tab` | 有 ghost 就接受补全；否则插入空格到下一个 4 列制表位 |
| `(` `[` `{` `'` `"` | **自动配对**：一次插入左右两个，光标停在中间；如果右边已经就是对应的收括号，则只跳过不多插 |
| `)` `]` `}` `'` `"` | 下一个字符正好是它 → 光标直接跳过 |
| `Backspace` | 先看选区；无选区时，若光标左右正好是一对配对标点（`()`、`[]`、`{}`、`''`、`""`），**一次删掉两个**；否则删一个字符 |
| `Del` | 删除光标后的字符（不移动光标） |
| `Opt` + 方向键 | 从当前位置开始**拉选区**（`sel_a`），继续按方向键扩大/缩小 |
| `Ctrl`/`Opt` + `c` / `x` / `v` | 复制 / 剪切 / 粘贴选区 |
| `Ctrl` + 方向键 | 滚动视图（上下按行、左右按字符宽），**光标不动** |
| `Esc` | 组词中 → 取消组词；终端开着且焦点在编辑 → 关终端；焦点在别处 → 回编辑 |

## 7. 快捷键总表

### Ctrl 组合（全局，编辑区优先）

| 快捷键 | 功能 |
|---|---|
| `Ctrl+B` | 文件侧栏 开 / 关（禅模式 ↔ 全分隔模式） |
| `Ctrl+`` 或 `Ctrl+J` | 终端面板 关 → 半屏 → 全屏 循环 |
| `Ctrl+R` | 运行当前文件（先保存，再通过屏幕终端里的 REPL 执行；`Ctrl+C` 可中断） |
| `Ctrl+S` | 保存（无路径时弹“另存为”输入框） |
| `Ctrl+N` | 新建文件 |
| `Ctrl+P` | 打开命令面板 |
| `Ctrl+E` | 问题面板 拉出 / 收起（焦点在终端时不抢，留给终端自己的 Ctrl+E） |
| `Ctrl+K` | 跳到下一个问题（顺手展开面板），重复按依次往后 |
| `Ctrl+Tab` | 切换焦点：编辑 → 终端 → 文件栏 → 问题面板（只列当前打开的） |
| `Ctrl+Q` | 退出 IDE 回引导页（退出前把光标/布局/面板状态落盘） |

### Alt / Opt 组合

| 快捷键 | 功能 |
|---|---|
| `Alt+]` 或 `Alt+↑` | 亮度 +1 档（共 6 档：512/614/716/818/921/1023） |
| `Alt+[` 或 `Alt+↓` | 亮度 −1 档 |
| **单击 `Opt`**（当作组合键用过则不触发） | 切换主题，8 套循环：蓝 / 白 / 绿 / 橙 / 青 / 紫 / 黄 / 红 |

### 焦点相关

| 焦点 | 方向键 | Enter | Esc |
|---|---|---|---|
| 编辑区 | 移动光标；`Ctrl` 按下时滚视图；`Opt` 按下时拉选区 | 换行 + 缩进 | 退出输入法 / 关终端 |
| 问题面板 | 上下选条目，光标跟着跳行 | 回编辑并定位 | 回编辑 |
| 文件栏 | 上下选文件，`←` 进上级目录 | 进目录 / 打开文件 | — |
| 终端 | — | 提交命令 | — |

> 这台机器的方向键在 **Fn 层**：物理键位是 `;`（上）`.`（下）`,`（左）`/`（右）。代码里对两套都做了识别，直接用 Fn+方向或未按 Fn 的 `;.,/` 都能操作。

## 9. 左侧文件栏（资源管理器）

- 标题栏显示**当前目录名**（根目录显示 `/`）；
- 列表顺序：**目录在前、文件在后**，同类按名字排序，目录带 `/` 后缀；
- `↑/↓` 移动选择，`←` 跳到上一级目录，`Enter`：目录则进入、文件则打开进编辑区；
- 右侧有细滚动条（条目数超过可视行数时出现）；
- 焦点只在侧栏时选中行才高亮（反色），焦点回编辑后仍显示文件名但不高亮。

## 10. 终端面板与模拟终端

### 终端面板（`Ctrl+`` / `Ctrl+J`）

三态：**关 → 半屏 → 全屏**。切到终端时会自动 `dupterm` 挂上 REPL；`Ctrl+方向键` 在终端里是**滚动输出视图**（上下按行、左右按 4 字符宽），不动光标，方便翻回完整报错。半屏和全屏的样子见 [实机演示](#实机演示) 第二、三张。

“运行当前文件”不是内联 `exec`，而是把 `exec(open("path").read())` 当作输入喂给屏幕 REPL，所以 `while True` 里也能用 `Ctrl+C` 真正打断。

### 模拟终端（`termapp.py`，懒加载）

纯 Python 的 Unix 风格小 shell，真文件系统、真命令，历史上限 64 条，输出缓冲 200 行：

```
help  ls [-l]  dir  cd  pwd  cat  head  mkdir  rmdir  rm
cp  mv  touch  echo  df  mem  date  uptime  clear  history  exit
```

| 按键 | 作用 |
|---|---|
| `Tab` | 路径补全：唯一匹配补到行尾，多个匹配列出来（最多 20 个） |
| `↑` / `↓` | 命令历史上下翻 |
| `Enter` | 执行 |
| `Esc` | 关闭终端回编辑 |

命令逐条 `try/except`，坏路径只回一行 `err:`，不会把 IDE 主循环打死。

## 11. 状态 / 日志 / 词频文件

全部在一个带指纹的子目录里，**不占 SD 根目录**：

```
/sd/M5ADV_IDE_9F3C7A2B/
├── logs/ide_YYYYMMDD.log
├── state.txt
└── imefreq.txt
```

`state.txt` 的键：

| key | 含义 | 取值 |
|---|---|---|
| `file` | 上次打开的文件 | 绝对路径 |
| `theme` | 主题序号 | 0–7 |
| `bright` | 亮度档 | 0–5（`dev._bld` 六档） |
| `side` | 侧栏 | 1=全分隔 / 0=禅模式 |
| `layout` | 布局名 | `full` / `zen` |
| `term` | 终端模式 | 0 关 / 1 半屏 / 2 全屏 |
| `err` | 问题面板 | 1 展开 / 0 收起 |
| `pos` | 光标位置 | `行,列` |

写盘时机：打开 / 保存 / 切主题 / 调亮度 / 切侧栏 / 切终端 / 切面板 / `Ctrl+Q`。开机时 `shell._Init()` **第一件事**就是建目录、写 `boot` 日志、读 `state.txt`，所以不等按键就恢复到上次界面（含光标位置与问题面板状态）。

日志一行一条：`2026-11-26 16:35:02 open /sd/demo.py`，事件类型 `boot / restore / open / save / theme / bright / layout / term`。

`imefreq.txt` 两列 `码位 次数`。

## 14. 已知限制与坑

- **中文行不高亮**：整行按纯文本渲染（字节索引宽度问题），所以中文注释/中文字符串里的关键字不会变色。
- **全文检查上限 400 行**（`CheckAll(limit=400)`）。
- **三引号按奇偶判断**：把 `"""` 写进注释可能误报一条。
- **词频只记单字**，不记词组顺序。
- **日志按天一个文件**，没有轮转与大小上限。
- **模拟终端入口冲突**（见第 8 节），v5 里打不开。
- 不插 SD 卡也能用，状态/日志/词频静默降级为内存态，重启即丢。
